# 💍Matrimony Hub

A full-stack **Matrimony Web Application** built using the **MERN Stack (MongoDB, Express, React, Node.js)**.  
This platform helps users find suitable life partners through biodata browsing, premium features, contact requests, and success stories.

## ✨ Website Features (Key Points)

1. Fully responsive design for **mobile, tablet, and desktop**
2. Secure authentication using **Firebase + JWT**
3. Private routes protected even after page reload
4. Biodata creation with **auto-generated biodataId**
5. Biodata browsing with **filtering & pagination**
6. Premium biodata system with admin approval
7. Contact request system with **Stripe payment**
8. Favorite biodata management
9. Success story posting & display
10. Admin dashboard with statistics and management
11. SweetAlert notifications for all CRUD operations
12. TanStack Query used for all GET requests
13. Environment variables used for Firebase & MongoDB credentials
14. No Lorem Ipsum text used
15. Separate dashboards for **User & Admin**
